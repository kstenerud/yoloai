=== WHAT THIS FILE DOES AND DOES NOT SETTLE ===
Settles: an address moves on an ordinary restart on BOTH backends, with a fresh MAC each
time; the tart lease pool is exhausted on this host; apple does not use that pool. Two
consecutive restarts for tart, one each for the apple guests — so the tart leg is n=2 and
the apple leg n=1 per guest.

Does NOT settle: whether the address is determined by START ORDER. Every guest here was
restarted in place, one at a time, in the same order — which is also the order round 2's
post-reboot half used. That is the confound this control was written to expose and cannot
itself remove; `reboot_post.sh` reverses the order (P10) to answer it.

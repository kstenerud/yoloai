== C SPLIT-HORIZON — names the host's resolver sees and the guest's may not ==
        This is the case dns-parity.txt named as most likely to diverge. Under host pf the
        HOST's answer is what lands in the dst table, so a name only the host can resolve
        produces an allowlist entry pointing where the guest will never send.
        tailnet FQDN (self)        host=100.x.x.x(cgnat)              guest=100.x.x.x(cgnat)
             ==> agree
        tailnet FQDN (peer)        host=100.x.x.x(cgnat)               guest=100.x.x.x(cgnat)
             ==> agree
        bare name + search         host=100.x.x.x(cgnat)               guest=UNRESOLVED
             ==> HOST-ONLY. Allowlisting this name writes an address into dst that the
                 guest cannot even resolve, so the entry is inert and the sandbox is
                 blocked from a domain the user explicitly allowed. Fail-closed, silent.
        mDNS .local                host=127.0.0.1 192.168.0.157 192.168.139.3 192.168.64.1 guest=UNRESOLVED

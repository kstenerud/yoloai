== V2 FAULT F1 'SHADOWED' — the reference is PRESENT and pf still never descends ==
        pf.conf's own comments warn that system services insert anchors into the main ruleset at
        runtime. Rules are first-match with 'quick', so anything inserted ahead of the com.apple
        anchor point shadows it. Here that is simulated with one 'pass quick all' line, loaded from a
        copy of /etc/pf.conf — so the reference detector A counts is still right there in the ruleset.
